# 📚 Study Planner App

A simple and effective **web-based study planner** built with **HTML, CSS, and JavaScript (Local Storage)**.
This project helps students **organize their study schedules, set goals, manage tasks, track time with a Pomodoro timer, and analyze productivity** — all in one place!

---

## 🚀 Features

✅ **Dashboard** – Quick overview of progress, pending tasks, and study stats
✅ **Task Manager** – Add, edit, mark complete, and delete study tasks
✅ **Goal Tracker** – Define and track long-term study goals
✅ **Pomodoro Timer** – Focus mode with a circular progress animation
✅ **Analytics** – Track daily/weekly study progress (charts & summaries)
✅ **Data Persistence** – Uses **Local Storage** to save all tasks, goals, and stats
✅ **Responsive Design** – Works on desktop and mobile screens

---

## 🖥️ Tech Stack

* **Frontend:** HTML, CSS (Flexbox, Grid, Responsive Design)
* **Logic & Storage:** JavaScript (Vanilla JS, Local Storage API)
* **Charts (Optional):** Chart.js (for analytics visualization)

## ⚡ Installation & Setup

1. Clone the repository

   ```bash
   git clone https://github.com/your-username/study-planner-app.git
   cd study-planner-app
   ```

2. Open `index.html` in your browser

   ```bash
   start index.html   # (Windows)
   open index.html    # (Mac)
   xdg-open index.html # (Linux)
   ```

3. That’s it! 🎉 No server or build setup needed (pure HTML, CSS, JS).

## 📖 Usage

1. Navigate using the **sidebar**:

   * 📊 **Dashboard** – Quick stats & progress
   * ✅ **Tasks** – Add or complete tasks
   * 🎯 **Goals** – Define study goals
   * ⏳ **Timer** – Focus using Pomodoro technique
   * 📈 **Analytics** – View progress reports

2. All your data is saved automatically in **Local Storage** — so it stays even after closing the browser.
